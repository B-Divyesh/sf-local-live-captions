# Landing-page copy audit

Audited 29 August 2026 from the shipped landing-page source in `src/main.ts`.
Counts treat hyphenated terms, prices, dates, and version numbers as one word.
Interface fragments, image alternative text, and every download state are included.
No line exceeds 22 words. No line contains a banned marketing use. The single
use of “unlock” describes literal feature gating and says that no feature is
unlocked by payment.
